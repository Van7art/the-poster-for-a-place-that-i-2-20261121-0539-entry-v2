A travel poster for **Velmara**, a place that isn't there: a small village with lit windows on a floating island, drifting above a sea of clouds at golden hour, waterfalls spilling off its rim into the mist below. The poster is rendered entirely in pure-stdlib Python — a hand-built PNG writer (zlib + struct), gradient skies, vector shapes, and a built-in 5x7 bitmap font for the lettering. No images, no network, no dependencies.

## Run it

```sh
python3 main.py
```

This writes the poster to `/output/entry.png` (768x1024 PNG, deterministic — every run produces the identical file).
